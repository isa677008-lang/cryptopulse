# CryptoPulse — единый проект

CryptoPulse — сайт криптовалютных котировок с API, автоматическим обновлением данных и интеграцией с Telegram.

## Возможности

- Получение криптовалютных котировок.
- Основной источник данных — CoinPaprika.
- Резервные источники — Binance и CoinGecko.
- Кэш котировок на сервере на 60 секунд.
- Автоматическое обновление страницы каждые 60 секунд.
- Кнопка ручного обновления котировок.
- Telegram-команда `/start`.
- Кнопка «Открыть CryptoPulse» в Telegram.
- API для получения рыночных данных.
- Проверка доступности сервиса через `/health`.
- Развёртывание на Render.

## Требования

- Python.
- GitHub для хранения кода.
- Render для размещения приложения.
- Telegram-бот, созданный через `@BotFather`.

## Настройка Render

Открой Render → сервис `cryptopulse` → **Environment**.

Добавь переменные окружения, которые использует текущая версия приложения:

- `TELEGRAM_TOKEN` — токен Telegram-бота.
- `WEBAPP_URL` — публичный HTTPS-адрес сайта Render, например `https://ВАШ-СЕРВИС.onrender.com`.
- `DATABASE_URL` — адрес PostgreSQL, если база данных используется приложением.

Адрес `WEBAPP_URL` указывай без `/api/prices` и без завершающего слеша.

**Важно:** названия переменных должны совпадать с теми, которые используются в `bot.py`. Если в коде указано другое имя, используй имя из кода.

Никогда не публикуй токены, пароли и API-секреты в GitHub, HTML, README или сообщениях. Храни их в переменных окружения Render.
